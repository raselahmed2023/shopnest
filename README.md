# ShopNest - E-Commerce Storefront

ShopNest is a modern and responsive mini e-commerce storefront built as the Week 6 Frontend Web Development Capstone Project.

## Live Demo

https://moonlit-mandazi-10a9e0.netlify.app

## Features

- Browse products from Fake Store API
- Search products by title
- Filter products by category
- Dynamic product detail pages
- Add products to shopping cart
- Increase and decrease product quantity
- Remove individual products
- Clear entire cart
- Live cart item count
- Live subtotal and total calculation
- Cart persistence using localStorage
- Checkout summary
- Customer information form
- Order success state
- Loading skeleton
- Error handling
- Responsive layout
- Toast notifications
- Confirmation modal
- Smooth UI animations

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Fake Store API
- Lucide React
- localStorage

## Reusable UI Components

The application reuses modular UI components such as:

- Button
- Product Card
- Modal
- Toast
- Loading Skeleton
- Search Bar
- Category Filter

This component-based structure reduces duplicated code and keeps the user interface consistent throughout the application.

## Pages

- Home / Product Listing
- Product Details
